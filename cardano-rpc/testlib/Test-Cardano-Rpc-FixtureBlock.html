mainBlockInMode :: (HasCallStack, MonadTest m, MonadIO m) => m (ByteString, BlockInMode) Source #

A genuine Byron BlockInMode decoded from the mainnet main-block golden fixture also used by ByronTx. The block handlers read scripted blocks through their real block reads, so the blocks must be real, valid blocks rather than placeholders; decoding an existing fixture through the same mkByronBlock smart constructor the node's ChainDB uses is the cheapest way to get one, and reuses a fixture already checked in for this purpose.

boundaryBlockInMode :: (HasCallStack, MonadTest m, MonadIO m) => m (ByteString, BlockInMode) Source #

A genuine Byron BlockInMode decoded from the mainnet epoch-boundary golden fixture also used by ByronTx; see mainBlockInMode. Distinct from it (a boundary block instead of a main block, at a different slot and hash), so a two-block script has two genuinely different blocks to distinguish, for free.
